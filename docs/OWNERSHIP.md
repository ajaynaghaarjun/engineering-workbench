# Ownership and assistance statement

This project was created for the engineering workbench assessment with substantial disclosed AI assistance. The implementation, tests, sample data and documentation were generated and edited during the recorded development session; no existing solver or frontend library was copied into the application.

Reused components are the C++ standard library, operating-system APIs and build/runtime toolchain components described in LICENSES.md. Hardware interface descriptions cite vendor documentation. Sample geometry and temperature data were self-created with AI assistance; the CSV is synthetic and is not represented as an actual ANSYS export.

The candidate must review this statement, understand the implementation, and confirm which parts they personally edited or verified before submission. This draft does not claim that the candidate independently wrote AI-generated source or performed tests that only the assistant ran.
