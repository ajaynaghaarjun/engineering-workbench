Host-connected design

Host PC → USB hub → STM32 Nucleo-F401RE (USB serial)
Host PC → USB hub → Digilent Arty A7-35T (USB UART / onboard JTAG)
Host PC → ST-LINK/V2 → Nucleo SWD target connector

ST-LINK/V2 is a debug adapter, not a compute board. The selected STM32 target uses SWD, supported by this JTAG/SWD adapter. Arty uses its onboard Digilent programming interface; adapters are not interchangeable.

See docs/EMBEDDED_DESIGN.md for voltage domains, grounding, pin ownership, connectors and safe integration.
